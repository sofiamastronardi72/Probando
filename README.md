# Mi Workout

App de entrenamiento personal (web app instalable en el celular).

- **Hoy**: rutina del día (Casa / Gym), con video, series, explicación, peso usado y "marcar completado".
- **Semana**: programa de varias semanas (Gym: 7 semanas desde el 19/10); armar cada día, reordenar, copiar días o semanas.
- **Videos propios**: se cargan desde el celular y quedan guardados solo en el teléfono.
- **Ejercicios**: biblioteca propia; crear, editar, borrar y cambiar ejercicios por otros del mismo músculo.
- **Más**: exportar / importar respaldo.

Los datos se guardan en el navegador del teléfono. No requiere servidor ni cuenta.

## Probar en la compu

```
python3 -m http.server 8000
```
y abrir http://localhost:8000
